# DocShift — Document Workbench

## Purpose
DocShift is a private, client-side document workbench that enables users to convert, view, and manipulate documents entirely within the browser without uploading files to any external server.

## Tech Stack
- **Build & Language**: Vite, TypeScript
- **Document Engines**: `pdf-lib`, `mupdf`, `docx`, `mammoth`, `xlsx`, `jszip`
- **Testing & Quality**: Playwright, custom privacy validation scripts

## About
Built with a strict zero-retention guarantee, DocShift processes PDFs, DOCX, and spreadsheets locally using WebAssembly and client-side JavaScript libraries. Your files never leave your device.
